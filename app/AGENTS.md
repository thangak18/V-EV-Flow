# `app/` agent instructions

Read [root instructions](../AGENTS.md), [application SPEC](SPEC.md), the shared [data contract](../docs/DATA_CONTRACT.md) and [API contract](../docs/API_CONTRACT.md), then the assigned [implementation plan](../docs/superpowers/plans/README.md). Before editing backend/frontend paths, read their `AGENTS.md` and nearest `SPEC.md`.

Runtime source, fixtures, and product tests stay here. Owner boundaries are documented in [CONTRIBUTING](../CONTRIBUTING.md) and the module specs. Shared contracts, generated artifacts, dependencies, root tooling, CI and another owner's module require a separate contract/tooling PR.

Use Makefile checks and the assigned implementation plan. Do not describe planned behavior or unexecuted checks as completed. Each change must map to acceptance criteria and retain limitations/data provenance.
